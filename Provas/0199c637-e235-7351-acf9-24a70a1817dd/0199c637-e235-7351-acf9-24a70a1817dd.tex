    \question
A função abaixo, escrita na linguagem C, quando executada para \( n = 5 \), faz quantas chamadas recursivas (excluindo a primeira chamada da função)? 
\begin{verbatim} int fat (int n) 
{ 
if (n == 1) return n; 
else return (n*fat(n-1)); 
} 
\end{verbatim}
\begin{choices}
\choice 4
\choice 5
\choice 1
\choice 0
\choice 6
\end{choices}

    u := u - 1;

    x := 4;
    y := 2;

\choice 7
\choice 8
\choice 10
\end{choices}
